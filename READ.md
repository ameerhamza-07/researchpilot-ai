
# ResearchPilot AI

An AI-powered research paper assistant built with
Python, NLP, Hugging Face, and Retrieval-Augmented
Generation (RAG).

## Planned Features

- Research paper PDF ingestion
- Semantic search over research papers
- LLM-powered question answering
- Answers with source citations
- Hybrid retrieval and reranking
- Retrieval and answer quality evaluation

## Tech Stack

- Python
- PyMuPDF
- Sentence Transformers
- FAISS
- Hugging Face
- LangChain
- FastAPI
- Streamlit

## Project Status

Currently building the PDF ingestion and semantic
search pipeline.
